Native Stage Game Options controller navigation - 2026-10-20

Original Stage Game Options now accepts D-pad Up/Down to focus Sound and
Backlight. A advances the focused option; Left/Right change the Sound mode.
The original native option handlers still apply the changes. B returns to the
pause menu. Real touch input takes priority. When touch and pad input arrive
together, the touch lanes stay live while the controller key record is masked.
Controller-generated touch and raw button changes are scoped to one PS_Update
call and restored immediately.

Implementation:
- hal/pc_pause_settings.cpp tracks controller focus and queues native actions.
- hal/stage_options_input.cpp scopes synthetic touch lanes and masks the
  controller key record while the original PS_Update handler runs.
- tools/boot_closure.py adds the frame scope to the PC-generated dScStage_c
  translation unit. No matched decomp source was changed.
