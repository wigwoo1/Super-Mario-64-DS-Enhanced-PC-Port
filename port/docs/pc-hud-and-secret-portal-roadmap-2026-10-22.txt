# PC HUD and secret portal follow-up — 2026-10-22

## Minimap counters

Keep always-visible Star, coin, health, and life counters beside the minimap,
placed along one side. Use the original in-game icons/sprites for each counter;
do not draw substitute pixel-art icons. Show health and lives as separate
counters. Scale the icons with the minimap size setting, and keep the existing
minimap position and opacity controls usable when laying out the HUD. The
current overlay shows Star, coin, and life values with newly drawn placeholder
icons; replacing those icons with the game's own art and adding the health
counter are still required.

Sprite source audit: the original HUD uses `OAM::POWER_STAR`, `OAM::COIN`, and
the character-specific `OAM::LIFE_ICONS[]` templates. Its health display is
drawn by `dMeter_c::RenderHealthMeter` from the original meter sprite/palette
tables. `dMeter_c::InitResources` loads the language-specific OBJ graphics and
palette files into main/sub OBJ memory (the default-language HUD graphics
include file `0x269`; the shared minimap resource is `0x229`). The PC overlay
does not currently initialize or render those meter resources, so changing the
placeholder shapes alone would not use the game's art. The port needs a way to
reuse the existing templates without damaging the scene's live OBJ resources,
then compose them at the minimap's configured size and position.
