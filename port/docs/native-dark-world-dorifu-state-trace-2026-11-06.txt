Replay evidence
---------------
The accepted 12-Star Mario QA fixture and complete native course route were
replayed for 23,000 frames with audio submission muted. Exit code was 0, audio
errors were 0, submitted samples were 0, and both copied save payloads match
the fixture byte-for-byte. A screenshot was captured at frame 23,000.

The original KM1_DORIFU actor (ID 134, UID 132) was sampled 1,231 times from
tick 10,625 through 22,995. Every sample remained active plank 4, state 0,
event bit 0, collision mask 0x10. This confirms it remains in its original
waiting state with only the fifth plank collision enabled. It does not prove
that Mario reaches the stairs or triggers their animation.

The original level placement table has a native floor switch (actor ID 11) at
(3855, 1700, -6), parameter 0x2a02, and the drifting stairs at
(5155, 1700, -6), parameter 0xff00. The recovered switch code decodes event
bit 0 from 0x2a02 and sets that bit when pressed; the stairs read event bit 0.
The replay did not reach/press that switch. Next work should use ordinary
player inputs to reach the switch and verify the stairs move through planks
4..0, then return as the switch event clears. Do not report the stairs as
traversable until collision and movement are observed in a targeted replay.
