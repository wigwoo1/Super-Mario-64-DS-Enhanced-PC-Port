Native castle birds: diagnostic integration, partial acceptance

The original castle level now has the SBIRD343 profile registered with its
native factory. Original model/animation resources and flock logic are linked.
The host transform replaces the mixed member/free-function state table with a
typed switch and translates the remaining ARM hatch to host C++.
The generic host transform owns resource handle construction/destruction.
Matched source and headers are unmodified. Layout and original profile metadata
are checked against the local extraction; no extracted assets are public inputs.

tests pass. Original File A/castle approach replay spawns leader+two followers,
shows birds taking flight, starts and completes original chirp effect3:106, and
cleans the departed flock. Runtime exits normally with zero mixer errors and
unchanged isolated seed saves. Real PCM captured before an output-only mute gate;
every submitted speaker buffer is silent. Listening fidelity is not accepted.

leaders, returns outside and reloads them with fresh IDs. The western flock
then renders/flies/cleans and completes its chirp again. Final Yoshi idle and
controllable, seed saves unchanged, zero mixer errors and silent submissions.
