Wanted PC Settings menu polish - 2026-10-16 (Luna Medium)

Status: VERIFIED. This is a small presentation update to the verified Wanted
settings menu. ROM-matching src/ and include/ remain unchanged.

Visible wording changes in port/hal/pc_pause_settings_state.cpp:
- FPS LIMIT -> FRAME RATE, with the FPS unit shown.
- ANISO FILTER -> ANISOTROPIC.
- Minimap rotation now says MAP ROTATION FOLLOW/UPRIGHT.
- Opacity and map size now display percentages. Map size uses the same
  tenths-of-a-percent conversion as the renderer; opacity is rounded to a

- Minimap position uses X/Y percentages, matching the normalized output
  coordinates used by the renderer.

- MG SCREENS now reads MINIGAME VIEW.
