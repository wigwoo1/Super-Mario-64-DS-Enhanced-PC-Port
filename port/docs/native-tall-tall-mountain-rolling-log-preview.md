# Tall Tall Mountain rolling log preview

The native port registers Tall Tall Mountain’s rolling log using the same movement and collision code as the Lethal Lava Land log, with the mountain log’s own resources and travel limit.

The native actor-data audit passed. A muted replay entered Mission 1 through the original painting and mission selector, walked near the course entrance, and confirmed that the mountain log spawned. The replay did not reach the log. Riding its collision surface, moving across it, and completing the mission remain unverified.
